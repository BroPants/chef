## Phase 2：v1.1 灵感发现（当前迭代）

**目标**：从「被动工具」升级为「主动灵感来源」，提升用户每日打开率

### 2.1 每日随机推荐（P0）

| 序号 | 任务 | 对应需求 | 说明 |
|------|------|----------|------|
| 2.1.1 | 精选菜品图库建设 | R-105 | 后端录入 ≥ 100 道菜品，含高质量图片、名称、难度、时长 |
| 2.1.2 | 推荐接口开发 | R-101 | `GET /api/recommendations/daily` |
| 2.1.3 | 首页推荐卡片 UI | R-101 | 菜品图（16:9）+ 名称 + 标签，圆角卡片样式 |
| 2.1.4 | 随机逻辑 + 去重 | R-102 | 记录最近推送历史，避免连续重复 |
| 2.1.5 | 点击直达菜谱 | R-103 | 点击卡片跳转菜谱详情页，参数传递方式同识别结果 |
| 2.1.6 | 换一换按钮 | R-104 | 手动刷新推荐，带 fade 过渡动画 |

### 2.2 外部内容链接（P0）

| 序号 | 任务 | 对应需求 | 说明 |
|------|------|----------|------|
| 2.2.1 | 外部内容库建设 | R-109 | 人工整理 B 站视频 + 小红书笔记，按菜品名索引（方案 A） |
| 2.2.2 | 外部内容接口 | R-106~R-108 | `GET /api/content/external?dish=xxx` |
| 2.2.3 | 菜谱页「相关教程」区块 UI | R-111 | 位于步骤之后，横向卡片列表，标注平台来源 |
| 2.2.4 | 外链跳转 | R-110 | 优先 webview，降级至复制链接 |
| 2.2.5 | 加载骨架屏 + 超时空态 | - | 超 2s 未返回则展示「暂无相关内容」 |

### 2.3 迭代完成标准

- [ ] 首页推荐卡片正常展示菜品图片及信息
- [ ] 每次 onShow 随机刷新，连续打开不重复
- [ ] 点击推荐卡片可进入对应菜谱详情
- [ ] 菜谱页底部展示 ≥ 1 条 B 站视频和 ≥ 1 条小红书笔记
- [ ] 外链点击可正常跳转
- [ ] 两个功能均有空态处理

## Phase 3：v1.2 体验深化

**目标**：提升下厨体验，增强工具实用性

| 序号 | 任务 | 对应需求 | 说明 |
|------|------|----------|------|
| 3.1 | 步骤语音播报 | R-112~R-114 | TTS 合成 + 音频缓存，手势控制上一步/下一步 |
| 3.2 | 食材购物清单 | R-115~R-117 | 勾选食材 → 生成清单 → 复制/分享 |
| 3.3 | 难度等级与时长 | R-008, R-009 | 菜谱详情页增加字段展示 |
| 3.4 | 多菜品识别 | R-005 | 识别图中多道菜，返回列表供用户选择 |
| 3.5 | 收藏功能 | R-012 | 菜谱页收藏按钮，个人中心收藏列表 |
| 3.6 | 节令推荐 | R-118, R-119 | 根据节气/节日调整首页推荐内容，添加「应季」标签 |

## Phase 4：v2.0 社区生态

**目标**：社交传播与深度使用，构建内容生态

| 序号 | 任务 | 对应需求 | 说明 |
|------|------|----------|------|
| 4.1 | 食材反查菜谱 | R-120, R-121 | 输入现有食材，AI 推荐可做菜品 |
| 4.2 | 营养价值展示 | R-010 | 热量、蛋白质等营养成分 |
| 4.3 | 分享功能 | R-014 | 生成菜谱分享卡片，分享至好友/朋友圈 |
| 4.4 | 菜谱文字搜索 | 扩展 | 首页搜索框，直接搜索菜品名称 |
| 4.5 | 个人中心 | 扩展 | 历史记录完整列表、收藏夹、设置 |
| 4.6 | 数据统计与推荐优化 | 扩展 | 埋点、低点击推荐降权、个性化推荐 |

## 技术债与持续优化

| 事项 | 说明 | 时机 |
|------|------|------|
| B 站 API 接入评估 | 调研官方 API 可用性，替代人工维护方案 | v1.1 上线后 |
| 推荐图片 CDN 接入 | 精选图库迁移至 CDN，提升加载速度 | v1.1 发布前 |
| TTS 费用控制 | 语音合成结果缓存策略，避免重复计费 | v1.2 开发时 |
| 小程序审核合规检查 | 外链跳转需符合微信平台规范，提前对接审核 | v1.1 发布前 |
